## ▶️ Como executar os arquivos

1. Instale o Python pelo [site oficial](https://www.python.org/downloads/).
2. Clone este repositório:

   ```bash
   git clone https://github.com/araujoc-dev/FUNDAMENTOS-PYTHON.git
   ```

3. Entre na pasta do projeto:

   ```bash
   cd FUNDAMENTOS-PYTHON
   ```

4. Execute um arquivo Python, substituindo `arquivo.py` pelo nome do script desejado:

   ```bash
   python arquivo.py
   ```

   Em alguns ambientes Windows, pode ser necessário usar:

   ```bash
   py arquivo.py
   ```
